Coming soon

  • Shared planning: calendar view with the week's planned tasks, by day, by member.
  • Tablet / kiosk view: tablet-adapted layout + always-on mode to display the app in the entryway, living room or kitchen.
  • Mini-onboarding on first effort/frequency vote: in addition to the "+ info" modals already in place, a small step-by-step tutorial the first time to explain what's being asked.

Later

  • Differentiated accept/refuse grace period for the effort bump: when the app proposes to bump the effort of an often-late task, apply a short cooldown (50% of the analysis window) if the user accepts the bump (to let the adjustment produce its effect), and a long cooldown (100%) if the user refuses (to respect the "no"). For now a single 70% cooldown is applied in both cases.
  • Extended family mode: multiple linked households (parents + grandparents who see each other's tasks), pro version for airbnb / long-term coloc.
